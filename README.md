# Adaptive Quiz System Using Reinforcement Learning

A Python-based adaptive quiz application designed to personalize question difficulty based on learner performance.

## Overview

The Adaptive Quiz System aims to provide a more personalized assessment experience by adapting quiz questions according to a learner's responses. The project explores how reinforcement learning can support adaptive question selection.

## Features

- Interactive quiz application
- Question bank management
- User authentication, if implemented
- Adaptive question difficulty using reinforcement learning
- Quiz results and performance tracking, if implemented
- Database-backed data storage

## Technology Stack

- **Language:** Python
- **Interface:** See the application's implementation
- **Database:** SQLite
- **Learning approach:** Reinforcement learning
- **Testing:** See the `tests` directory
